# Triage labels

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | Needs maintainer review |
| `needs-info` | Needs more information |
| `ready-for-agent` | Specified task; check native blockers before work |
| `ready-for-human` | Needs operator access or a human decision |
| `wontfix` | Will not be done |

These are the default skill roles with the same label names. Blocked tasks
can remain specified and ready for an agent, but work must wait for blockers.
